# ragdoll remux

Copy every packet from one container into another without decoding or re-encoding. The input is memory-mapped and packets are written with vectored I/O, so a remux is usually limited by memory bandwidth.

```sh
ragdoll remux <IN> <OUT> [--format <EXT>] [--json]
```

## Options

| Option | Description |
| :-- | :-- |
| `<IN>` | Input file, or `-` for stdin. |
| `<OUT>` | Output file, or `-` for stdout. The container is chosen from the extension. |
| `--format <EXT>`, `-f <EXT>` | Override the output container, for example `mkv` or `ts`. Without it, output to `-` is MPEG-TS. |
| `--json`, `-j` | Print the summary as JSON. |

## Supported conversions

| From ↓ / To → | MP4 / MOV | Matroska / WebM | MPEG-TS | WebVTT / SRT |
| :-- | :-: | :-: | :-: | :-: |
| **MP4 / MOV** | <S v="yes" /> | <S v="yes" /> | <S v="yes" /> | <S v="yes" /> |
| **Matroska / WebM** | <S v="yes" /> | <S v="yes" /> | <S v="no" /> | <S v="yes" /> |
| **MPEG-TS** | <S v="yes" /> | <S v="yes" /> | <S v="yes" /> | <S v="no" /> |

The WebVTT / SRT column writes the cues of the input's subtitle tracks to one file (with several subtitle tracks, their cues are merged). Audio files have their own copies: FLAC → FLAC, Ogg or Matroska; Ogg → Ogg, Matroska, or FLAC when the Ogg stream is FLAC. YUV4MPEG2 → YUV4MPEG2, WAV → WAV and MPEG-TS → MPEG-TS are straight byte copies, and WebVTT and SRT convert into each other.

Any other combination is not a remux. In that case `remux` falls back to [`transcode`](/docs/cli/transcode/) with default settings (H.264, QP 20), and the summary line starts with `[ragdoll transcode]` or `[ragdoll transcode-audio]` instead of `[ragdoll remux]`. MPEG-TS to WebVTT / SRT is not supported.

## Examples

```sh
ragdoll remux input.mp4 output.mkv
ragdoll remux input.ts output.mp4
ragdoll remux input.mkv captions.srt

# Remux to stdout and inspect the result.
ragdoll remux input.mp4 - --format ts | ragdoll probe -
```

```text
[ragdoll remux] sample.mp4 -> sample.mkv | frames=60 gops=1 threads=1 | in=137757 B out=137352 B (1.00:1) | 0.31 ms (193562.7 fps, 0.888 GB/s)
[ragdoll remux] sample.mp4 -> sample.ts | frames=60 gops=1 threads=1 | in=137757 B out=147956 B (0.93:1) | 0.29 ms (204192.8 fps, 0.972 GB/s)
```

## What is preserved

- All packets, timestamps and keyframe flags.
- Codec configuration: H.264 `avcC` is carried into Matroska `CodecPrivate`, and converted to and from Annex-B start codes for MPEG-TS.
- A `Cues` keyframe index is generated for Matroska output. MP4 output is always written fast-start, with `moov` before `mdat`.
