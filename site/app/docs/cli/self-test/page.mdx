# ragdoll self-test

Run the optimized kernels next to their scalar references on this machine, check that the results are identical, and print the throughput of both.

```sh
ragdoll self-test
```

`self-test` is the quickest way to confirm that a build is correct on new hardware. It takes a few seconds and needs no input files.

## Reading the table

- **Scalar** is the portable reference implementation, compiled with the same optimization settings. The compiler is free to auto-vectorize it, which is why some speedups are modest.
- **SIMD** is the kernel the dispatcher picked for this machine. The column is labelled `NEON SIMD` on every architecture. On `aarch64` it is the NEON kernel. On `x86_64`, plane SAD and SSE, the SSIM statistics, the start-code scanner, RBSP unescaping, 8-tap scaling and YUV-to-RGB have AVX2 kernels; the other rows run the scalar reference in both columns, so their speedup is about `1.00x` and the difference is noise.
- **Check** must read `EXACT`: the two outputs are compared bit for bit, not within a tolerance. If any kernel disagrees with its reference, `self-test` stops with an assertion failure and a non-zero exit status; otherwise it exits with `0`.
- The trailing lines cover non-tabular checks: CRC tables, Exp-Golomb and Rice bit I/O round trips, 128-bit timestamp arithmetic, quality metrics, in-memory container throughput and a two-frame H.264 encode and decode. "Zero-copy demux" measures how fast packet views are produced over a mapped file, which is why it exceeds memory bandwidth. The PMU instruction and cycle counts read `0` where the OS does not expose them, as on Linux.

Set `RAGDOLL_SIMD=scalar` to make the dispatcher pick the scalar kernels, which turns both columns into the reference implementation. `self-test` takes no arguments; passing one is a usage error (exit status `2`).

The same checks run in CI as ordinary unit tests (`cargo test --workspace`), across odd dimensions and unaligned tails that `self-test` does not exercise, and CI runs the whole test suite a second time with `RAGDOLL_SIMD=scalar`.
