# ragdoll self-test

Run every optimized kernel next to its scalar reference on this machine, check that the results are identical, and print the throughput of both.

```sh
ragdoll self-test
```

`self-test` is the quickest way to confirm that a build is correct on new hardware. It takes a few seconds and needs no input files.

## Reading the table

- **Scalar** is the portable reference implementation, compiled with the same optimization settings. The compiler is free to auto-vectorize it, which is why some speedups are modest.
- **SIMD** is the hand-written kernel for the detected instruction set. On `x86_64` this column currently runs the scalar path too, because AVX2 kernels have not been written yet.
- **Check** must read `EXACT`: the two outputs are compared bit for bit, not within a tolerance.
- The trailing lines cover non-tabular checks: CRC tables, Exp-Golomb and Rice bit I/O round trips, 128-bit timestamp arithmetic, and in-memory container throughput. "Zero-copy demux" measures how fast packet views are produced over a mapped file, which is why it exceeds memory bandwidth.

The same checks run in CI as ordinary unit tests (`cargo test --workspace`), across odd dimensions and unaligned tails that `self-test` does not exercise.
