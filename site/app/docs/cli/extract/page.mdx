# ragdoll extract

Write a single frame, or a grid of evenly spaced thumbnails, to an image or a raw video file.

```sh
ragdoll extract <IN> <OUT> [--at <TIME>] [--json]
ragdoll extract <IN> -o <OUT> --thumbnails <N> [--grid <CxR>] [--json]
```

## Options

| Option | Default | Description |
| :-- | :-- | :-- |
| `<IN>` | | Input video file. |
| `<OUT>`, `-o`, `--output` | | Output path. `.ppm` writes an RGB image; `.y4m` writes YUV frames. |
| `--at <TIME>` | `0` | Timestamp of the frame to extract, in seconds or `HH:MM:SS.mmm`. |
| `--thumbnails <N>` | | Build a contact sheet of `N` frames sampled evenly across the video. |
| `--grid <CxR>` | `4x4` | Columns and rows of the contact sheet. |
| `--json`, `-j` | | Print the summary as JSON. |

## Examples

```sh
# One frame, one second in.
ragdoll extract talk.mp4 still.ppm --at 1.0

# The same, with an HH:MM:SS timestamp.
ragdoll extract talk.mp4 still.ppm --at 00:12:30.000

# A 4×4 contact sheet.
ragdoll extract talk.mp4 -o sheet.ppm --thumbnails 16 --grid 4x4

# A 6×2 strip of thumbnails.
ragdoll extract talk.mp4 -o strip.ppm --thumbnails 12 --grid 6x2
```

```text
[ragdoll extract] sample.mp4 -> sheet.ppm | frames=16 gops=1 threads=10 | in=7844139 B out=2886016 B | 26.06 ms (613.9 fps)
```

## Notes

- Each thumbnail is the source frame scaled to `width / columns` by `height / rows` (at least 64×36) with the polyphase scaler, then converted to RGB using the track's colorimetry.
- PPM is the binary Netpbm `P6` format. Most image viewers open it directly; convert it to PNG with any image tool. Native PNG and JPEG output are planned for milestone M9.
- The whole video is currently decoded before frames are selected. For long inputs this is slower and uses more memory than a keyframe seek would.
