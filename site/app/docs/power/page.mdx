# Power modes

Media work is often done on laptops. Ragdoll lets you trade speed for battery life with a single flag, and applies the choice to every worker thread it spawns.

```sh
ragdoll transcode input.mp4 output.mp4 --power-mode efficiency
ragdoll transcode input.mp4 output.mp4 --battery-saver   # same thing
```

## Modes

| Mode | Aliases | Threads | macOS QoS class | Pipeline memory budget |
| :-- | :-- | :-- | :-- | :-- |
| `performance` (default) | | All logical cores | `QOS_CLASS_USER_INITIATED` | 256 MiB |
| `balanced` | `default`, `normal` | All logical cores | `QOS_CLASS_DEFAULT` | 256 MiB |
| `efficiency` | `eco`, `battery`, `low-power`, `e-core` | Efficiency-core count, or half the logical cores if that is larger | `QOS_CLASS_BACKGROUND` | 64 MiB |

An explicit `--threads N` on `transcode` overrides the automatic thread count.

## How efficiency mode works

On Apple Silicon, threads at `QOS_CLASS_BACKGROUND` are scheduled onto the efficiency cluster, which lets the performance cores stay power-gated. Ragdoll reads the core counts from `hw.perflevel0.logicalcpu` and `hw.perflevel1.logicalcpu` and sizes its worker pool to the efficiency cluster. The pipeline's memory budget also drops from 256 MiB to 64 MiB.

The work takes longer but uses much less energy. On an M4, the end-to-end workloads run roughly 2.5× to 6× slower in efficiency mode and use roughly 3× to 6× less energy than in performance mode. Run [`ragdoll bench`](/docs/cli/bench/) to see the numbers for your machine.

## Other platforms

On Linux and other systems there is no core-type information, so efficiency mode uses half the logical cores and the smaller memory budget. No QoS class is applied; thread placement is up to the OS scheduler.

## From Rust

```rust
use ragdoll_core::{PowerMode, set_global_power_mode, with_power_mode};

// Apply process-wide.
set_global_power_mode(PowerMode::Efficiency);

// Or scope it to one piece of work; the previous mode is restored afterwards.
let report = with_power_mode(PowerMode::Efficiency, || {
    ragdoll_pipeline::transcode_file_with_options("in.mp4", "out.mp4", &Default::default())
})?;
```
