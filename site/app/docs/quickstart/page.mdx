# Quickstart

This walkthrough generates its own test media, so you don't need any sample files. It takes about five minutes and touches every media subcommand. The output shown comes from a four-thread x86_64 machine; your timings will differ.

## 1. Generate test media

[`synth`](/docs/cli/synth/) writes procedural video (step bars and a moving pattern) or audio (a stereo tone). The output format follows the file extension.

```sh
ragdoll synth sample.mp4 --resolution 1280x720 --fps 30 --duration 2
ragdoll synth tone.wav --duration 3
```

```text
[ragdoll synth] procedural://1280x720@30fps -> sample.mp4 | frames=60 gops=4 threads=4 | in=82944000 B out=137757 B (602.10:1) | 308.84 ms (194.3 fps, 0.269 GB/s)
[ragdoll synth-audio] procedural://audio -> tone.wav | frames=1 gops=1 threads=1 | in=576000 B out=576044 B (1.00:1) | 5.16 ms (27921955.0 fps, 0.223 GB/s)
```

Most commands end with a one-line report: frames processed, GOPs, worker threads, bytes in and out, and wall time.

## 2. Inspect it

[`probe`](/docs/cli/probe/) reads the container index without decoding anything. Add `--gop-map` to see the keyframe structure.

```sh
ragdoll probe sample.mp4 --gop-map
```

## 3. Change containers

[`remux`](/docs/cli/remux/) moves packets between containers without decoding. It is limited by memory bandwidth, not by codec work.

```sh
ragdoll remux sample.mp4 sample.mkv
ragdoll remux sample.mp4 sample.ts
```

```text
[ragdoll remux] sample.mp4 -> sample.mkv | frames=60 gops=1 threads=1 | in=137757 B out=137352 B (1.00:1) | 0.31 ms (193562.7 fps, 0.888 GB/s)
[ragdoll remux] sample.mp4 -> sample.ts | frames=60 gops=1 threads=1 | in=137757 B out=147956 B (0.93:1) | 0.29 ms (204192.8 fps, 0.972 GB/s)
```

## 4. Re-encode

[`transcode`](/docs/cli/transcode/) decodes, optionally filters and scales, and re-encodes across GOP-parallel workers.

```sh
ragdoll transcode sample.mp4 small.mp4 --scale 640x360 --qp 24
ragdoll transcode tone.wav tone.flac
```

```text
[ragdoll transcode] sample.mp4 -> small.mp4 | frames=60 gops=4 threads=4 | in=137757 B out=45166 B (3.05:1) | 345.05 ms (173.9 fps, 0.001 GB/s)
[ragdoll transcode-audio] tone.wav -> tone.flac | frames=1 gops=1 threads=1 | in=576044 B out=138504 B (4.16:1) | 7.48 ms (19241075.8 fps, 0.095 GB/s)
```

The encoded file is the same whatever the thread count, so `--threads` and the power mode only change how long it takes.

## 5. Cut and join

[`cut`](/docs/cli/cut/) trims a clip, re-encoding only the GOP the cut starts in. [`concat`](/docs/cli/concat/) joins files, by packet copy when they match.

```sh
ragdoll cut sample.mp4 clip.mp4 --from 0.7 --to 1.6
ragdoll concat clip.mp4 clip.mp4 -o twice.mp4
```

```text
RAGDOLL CUT: sample.mp4 -> clip.mp4 | 27 video pkts (18 zero-copy copied, 9 boundary frames re-encoded), 0 audio pkts (84373 B in 318.43 ms)
RAGDOLL CONCAT: 2 segments -> twice.mp4 | 54 video pkts, 0 audio pkts (reencoded=false, 168035 B in 0.50 ms)
```

## 6. Package for streaming

[`package`](/docs/cli/package/) encodes an adaptive-bitrate ladder into CMAF segments with HLS and DASH manifests.

```sh
ragdoll package sample.mp4 -o hls
```

```text
RAGDOLL PACKAGE: sample.mp4 -> hls | 2 CMAF renditions x 1 segments | HLS=hls/master.m3u8 | DASH=hls/manifest.mpd (810089 B in 1216.47 ms)
```

## 7. Pull out frames

[`extract`](/docs/cli/extract/) writes a single frame at a timestamp, or a tiled contact sheet.

```sh
ragdoll extract sample.mp4 frame.png --at 1.0
ragdoll extract sample.mp4 -o sheet.png --thumbnails 16 --grid 4x4
```

## 8. Measure quality

[`metrics`](/docs/cli/metrics/) compares a distorted file against a reference. A remux is lossless, so this pair scores perfectly:

```sh
ragdoll metrics sample.mp4 sample.mkv
```

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ RAGDOLL PERCEPTUAL QUALITY METRICS (60 frames in 659.83 ms / 90.9 fps)
├──────────────────────────────────────────────────────────────────────────────┤
│ PSNR (dB)     : Y=inf dB | U=inf dB | V=inf dB | Avg=inf dB (6:1:1=inf dB)
│ SSIM (8x8)    : Y=1.00000 (inf dB) | Avg=1.00000 | 5-Scale MS-SSIM=1.00000
│ VMAF-Lite     : 100.00 / 100.0
└──────────────────────────────────────────────────────────────────────────────┘
```

## 9. Use pipes

`probe`, `remux` and `transcode` accept `-` as a path to read from stdin or write to stdout. When stdout is the output and no format is given, Ragdoll writes MPEG-TS.

```sh
ragdoll transcode sample.mp4 - --format ts | ragdoll probe -
```
